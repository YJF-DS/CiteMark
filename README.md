# CiteMark · 原文定位器

**写综述时引用了某篇文献，想知道这句话在原文 PDF 的哪个位置？**

CiteMark 用本地语义模型把 PDF 里所有意思相近的句子找出来、标黄、逐处跳转。<br>
AI 只负责找位置，**判断引用是否恰当永远是你**。

<sub>全本地计算 · 不联网 · 不上传 · 断网可用 · Windows</sub>

</div>

---

## 它解决什么问题

写综述最难的不是写字，是**核对**。

你在第 37 段写了「OA 软骨细胞自噬流受阻」，引了 [52]。三个月后回头，你已经想不起这句话在原文的哪一页、是原作者的结论还是你自己的引申。手动翻开 PDF Ctrl+F，只能搜关键词——原文换了个说法，你就搜不到。

CiteMark 做的是**语义检索**：不是找相同词，而是找意思相近的句子。你把综述里那句话粘进去，它把这本 PDF 里相关度最高的 3–6 句标黄，带相关度角标，可以逐处跳转。同一结论在摘要/讨论/结论里的其它复述，收进清单底部的「另有 N 处同题表述」，点开才显示淡黄——避免满页发黄。

一整篇综述要核对？用**夜间挂机**：睡前投喂一个 .docx + 一堆 PDF，早上收三件套（带超链接的 Word、带真实高亮注释的 PDF 副本、挂机报告）。

## 下载

到 [**Releases**](../../releases/latest) 页面下载 `CiteMark_v1.0.0_win64.zip`（约 175 MB，含离线语义模型），解压即用，**无需安装、无需 Python、无需联网**。

> 为什么这么大：语义模型完整打包在压缩包里，所以它才能在断网的电脑上工作。这是刻意的取舍。

## 快速开始

1. 解压到任意文件夹（路径别太长）。
2. 右键 `CiteMark.exe` → 发送到 → 桌面快捷方式，以后双击桌面图标。
3. 首次启动要加载语义模型，等几秒属正常。
4. 窗口没弹出？用 Edge 或 Chrome 手动打开 `http://127.0.0.1:8917/index.html`。
   **不要**直接双击 `index.html`——`file://` 方式浏览器会拦截组件。

需要 Edge 或 Chrome（Windows 自带 Edge 即可）。

## 功能

### 一、单篇定位

1. 切到「单篇定位」，粘贴综述里引用了某文献的那句话。
2. 把被引 PDF 拖进虚线框。
3. 点「找出原文相关处」→ 右侧出现 PDF 原文，只把最相关的 3–6 句标黄。

三档灵敏度可切换：

| 档位 | 行为 |
| --- | --- |
| 严谨 | 几乎逐字复述 |
| 均衡 | 默认 |
| 宽松 | 把重度改写也捞进来 |

### 二、夜间挂机（核心）

有一整篇综述要核对？睡前花 2 分钟投喂，让它在夜里把每一处引用都在对应 PDF 里定位、标黄、生成成品。

1. **选综述稿**（.docx）——用 Zotero 域引用写的效果最好（自动带题名/DOI）；纯数字引注 `[n]` 也可以，但要求文末有编号文献表。
2. **选被引 PDF**——可多选，一次丢几十上百个都行。
3. **成品放哪**——本机直写，落到 `软件目录\CiteMark成品\日期_综述名\`，不用选文件夹、不用授权。
4. 点「开始挂机」。先**预检**：自动把每篇文献对号到 PDF（DOI/标题匹配），对不上的会标出来让你手动指定。

早上收三件套：

- **晨间仪表盘**：每条引用按 🔴 红（两档都零命中，优先人工看）/ 🟡 黄（仅宽松档命中或扫描版/出错）/ 🟢 绿（均衡档有命中）排序。
- **软件内阅读器**：左边综述正文（每个引注是带命中数的可点徽标），点右侧打开该 PDF 并跳到第一处高亮。中间竖条可拖动调整两栏占比，比例会记住。
- **输出文件夹**：链接版 Word（每个 `[n]` 后插入 `↗P4` 上标超链接，点击打开高亮副本 PDF 并翻到该页）＋ `annotated_pdfs/`（每篇一份带真实高亮注释的副本）＋ 挂机报告.txt。

没有素材想先体验？夜间面板有「载入演示项目」，浏览器里现做一个小综述 + 3 篇 PDF，约一分钟跑完全流程。

## 隐私

全部计算在本机浏览器内完成，**不联网、不上传**。PDF 和综述稿都不会离开你的电脑。离线环境（断网）也能用。

本地服务只监听 `127.0.0.1`，不对外网开放。

## 已知边界

- **扫描版 PDF**（图片型）走 OCR，只给页码清单，不做页内高亮。
- **作者-年份制**（无编号文献表）的 docx 暂不能自动对号，需在预检表手动指定。
- 每本 PDF 夜里只解析**前 30 页**（绝大多数文献正文足够）。
- **黄色高亮是候选位置，不是判决**——是否引用恰当由你判断。
- **绝对路径链接的代价**：成品目录搬走或改名后，Word 里的 ↗ 会失效。要搬到别处用，请用「打包 ZIP」按钮。

## 常见问题

<details>
<summary>杀毒软件拦截？</summary>

加白名单/信任。程序是 Python 打包的单文件 exe，会起本地端口、写本地文件，容易被启发式规则误报。
</details>

<details>
<summary>端口被占？</summary>

自动顺延 8917–8928，无需处理。
</details>

<details>
<summary>点了没反应？</summary>

确认窗口地址是 `http://127.0.0.1:…/index.html` 而不是 `file://` 开头。
</details>

<details>
<summary>挂机中途想停？</summary>

直接关页面即可。重开后会提示「继续这次挂机」（成品目录里的 `state.json` 就是进度）。
</details>

<details>
<summary>上次挂机中断了，还能救吗？</summary>

能。重开页面 →「继续这次挂机」。已跑完的文献不会重跑。
</details>

<details>
<summary>提示「启动器是旧版」？</summary>

关掉窗口、重新双击桌面图标。新版启动器（v3）才带长路径支持。
</details>

## 技术说明

| 层 | 实现 |
| --- | --- |
| 语义模型 | Snowflake `arctic-embed-s`（Apache-2.0）本地部署，CLS 池化 + 查询侧检索前缀 |
| 推理 | transformers.js + ONNX Runtime Web；有 WebGPU 用 fp32（快 3–10 倍），否则 CPU WASM q8 兜底 |
| 并发 | 编码跑在 Web Worker，主线程只收进度（否则几百句推理会冻结界面） |
| PDF | pdf.js 解析 + pdf-lib 写入真实高亮注释 |
| OCR | tesseract.js（chi_sim + eng），仅扫描版触发 |
| 启动器 | Python 单文件 exe：本地静态服务器 + Edge `--app` 独立窗口 + 本机写盘接口 |

模型放在 `lib/models/`，通过 `T.env.allowRemoteModels = false` 强制离线，从根本上杜绝联网。
